# 충남 일자리 플랫폼 샘플

충청남도 지역의 일자리 창출을 주제로 제작한 원페이지 웹사이트 샘플입니다.

## 구성

- index.html — 웹페이지 구조
- style.css — 반응형 디자인
- script.js — 버튼 인터랙션

## 실행

index.html 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 Repository의 Settings → Pages로 이동합니다.
2. Build and deployment에서 Deploy from a branch를 선택합니다.
3. Branch를 main / root로 설정합니다.
4. 저장 후 GitHub Pages 주소에서 웹사이트를 확인할 수 있습니다.

> 본 프로젝트는 웹 개발 학습 및 포트폴리오용 샘플입니다. 페이지에 사용된 수치와 문구는 실제 정책 성과를 의미하지 않습니다.
